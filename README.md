# Aplikasi Biodata Diri (Laravel)

Aplikasi web sederhana berbasis **Laravel** yang memisahkan halaman publik (_welcome message_) dengan halaman manajemen data (_admin_), dengan fokus data **Nama**, **Kelas**, dan **Hobi**.

## Fitur Utama

- **Halaman Publik (`/`)**: Menampilkan informasi biodata diri secara langsung dari database kepada pengunjung.
- **Halaman Manajemen Admin (`/admin`)**: Halaman khusus untuk mengubah, memperbarui, dan mengelola konten biodata secara dinamis tanpa mengubah kode program.

## Teknologi yang Digunakan

- PHP & Laravel Framework
- Database (MySQL / SQLite)
- Blade Templating Engine
